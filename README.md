# Improving Human Motion Quality in Hunyuan and Wan2.2 Video Generation

This repository explores methods for improving human motion quality in text-to-video generation models, with a focus on **HunyuanVideo** and **Wan2.2**.

The project investigates motion-aware inference and selection strategies to reduce common artifacts such as **anatomical inconsistencies, phantom limbs, and unstable motion trajectories**, especially in complex or fast human movements.

It also includes evaluation pipelines for comparing baseline and motion-enhanced generations using human motion and video quality metrics.
